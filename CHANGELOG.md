# 📦 Souani Data Cleaner - Changelog

## [v4.0.1] - 2026-07-30 (Current Stable Version)
### Added
- Enterprise Dark Theme GUI built with Tkinter.
- Integrated `SplashScreen` with dynamic progress animation.
- Dynamic HTML Report generation after dataset processing.
- Multi-thread execution (`threading`) to prevent UI freeze during data cleaning.
- AI Executive Panel displaying dataset health, processing metrics, and risk assessment.
- Dialogs for `Settings` and `About` details.

### Fixed
- Fixed Tkinter `TclError: unknown option "-disabledbackground"` on Enterprise Button component.
- Resolved code truncation issues in GUI callbacks.
